# NetworkLab

这是湘潭大学 2022 级自动化与电子信息学院在 2024 年粤嵌实训课的课程项目代码合集。

仓库里主要包含多个嵌入式多媒体相关项目，覆盖视频播放、音乐播放、电子相册、语音控制、图像处理等功能模块。不同目录对应不同阶段或不同功能的实现，方便分别编译、调试和演示。

## 项目说明

本仓库的核心内容是基于粤嵌 GEC6818 开发板的多媒体交互项目，主要能力包括：

- 视频播放
- 音乐播放
- 电子相册
- 触摸屏交互
- 语音识别控制
- 文件路径与资源管理

其中部分项目还包含开发板端、虚拟机端和 PC 端的配套资源与说明文档。

## 目录结构

- `Project/`：课程项目的主要工程目录，包含源代码、头文件、库文件和素材资源。
- `video_player/`：视频播放器示例工程，带有独立的使用说明。
- `video_project/`：较完整的视频、多媒体与联网功能工程。
- `voice_project/`：语音识别相关工程与操作说明。
- `screen/`：屏幕交互、触摸、图片、音乐、视频等功能的拆分代码。
- `voice/`：语音识别相关资源。
- `File/`：工具、资料、库文件和教学素材。
- `pro2/`：开发板相关工程与说明。

## 编译与运行

不同子项目的编译方式可能略有区别，具体以各目录下的 `README.md`、`命令.md` 或源代码中的注释为准。一般流程如下：

1. 在 Linux 或开发板配套环境中配置交叉编译工具链。
2. 进入对应工程目录。
3. 使用 `Makefile` 或项目说明中的命令进行编译。
4. 将生成文件拷贝到开发板或对应运行环境执行。

例如，`video_player/README.md` 中给出了示例编译命令：

```bash
arm-linux-gcc ./src/*.c -I ./inc -o ./main.out
```

## 隐私文件处理

如果你本地有包含个人信息的文档，例如 `202205570105龚维学.doc`，不建议把它提交到 GitHub 仓库中。

推荐做法是：

1. 不要执行 `git add` 把它加入提交。
2. 在仓库根目录加入忽略规则，避免以后误提交。
3. 如果这个文件已经被 Git 跟踪，再执行 `git rm --cached 文件名`，只从仓库索引移除，不删除本地文件。

本仓库已经为该文件添加了忽略规则，后续不会被误加入提交。
